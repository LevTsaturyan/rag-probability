# RAG по тексту: вопросы и ответы по документу

## Что это
Система отвечает на вопросы на русском по загруженному текстовому документу. Она находит в тексте фрагменты, наиболее близкие по смыслу к вопросу, и формулирует ответ только на их основе, указывая источники. Протестирована на тексте по теории вероятностей и математической статистике (около 50 000 символов).

## Как работает
1. **Нарезка.** Текст делится на фрагменты (до 600 символов) по границам предложений; соседние фрагменты перекрываются на одно предложение.
2. **Векторизация.** Модель `paraphrase-multilingual-MiniLM-L12-v2` превращает каждый фрагмент в вектор из 384 чисел. Тексты со схожим смыслом получают близкие векторы.
3. **Поиск.** Вопрос кодируется той же моделью, и по косинусной близости выбираются 4 ближайших фрагмента.
4. **Генерация.** Фрагменты и вопрос передаются модели `Qwen2.5-1.5B-Instruct` с инструкцией отвечать строго по контексту. Если ответа в тексте нет, система сообщает об этом.
5. **Интерфейс.** Веб-демо на Gradio показывает ответ и найденные фрагменты со степенью сходства.

## Оценка качества поиска
Метрики: recall@5 (доля вопросов, где нужный фрагмент попал в топ-5) и MRR (среднее значение 1 / место правильного фрагмента). Правильным считается фрагмент, содержащий заранее заданную ключевую фразу.

| Набор вопросов | recall@5 | MRR |
|---|---|---|
| 5 вопросов (предварительно) | 1.0 | 0.8 |

## Ограничения
- Набор для проверки очень мал (5 вопросов), поэтому цифры предварительные.
- Часть ключевых фраз встречается в тексте несколько раз, и метрика может быть завышена.
- Измерялось только качество поиска, качество ответов языковой модели не оценивалось.
- Проверено на одном документе.

## Как запустить
1. Открыть `rag.ipynb` в Google Colab и включить GPU (Среда выполнения → Сменить тип → T4 GPU).
2. Выполнить ячейки по порядку.
3. Загрузить свой текстовый файл `.txt` в кодировке UTF-8 и задать вопрос в веб-интерфейсе.

## Планы
- Расширить проверочный набор до 20-30 вопросов и ужесточить ключевые фразы.
- Сравнить размеры фрагментов и разные модели эмбеддингов.
- Оценить качество самих ответов, а не только поиска.
